## 🌿 项目介绍

「息谷」是一款极简主义的网页端数字冥想与呼吸辅助工具。通过平滑舒缓的呼吸视觉动效与色彩节律，帮助用户在日常工作与学习间歇快速平复情绪、调整呼吸、恢复专注力。

### ✨ 核心特点
- 🌊 **艺术化视觉动效**：模拟潮汐起伏与呼吸引导动画。
- 🎨 **极简自然调色板**：采用舒适柔和的深谷暗色调配色，缓解眼部疲劳。
- 🚀 **即开即用**：纯静态前端，基于 HTML5 + Tailwind CSS 构建，无任何构建编译依赖。

### 🚀 运行方式
无需安装任何环境，使用任意现代浏览器直接打开 `index.html` 即可开始呼吸冥想。

## 🌿 Overview

**Breathe Valley** is a minimalist web application for guided breathing exercises and digital mindfulness. Designed to help individuals reset focus, alleviate anxiety, and practice mindful breathing throughout the day.

### ✨ Features
- 🌊 **Smooth Visual Rhythm**: Calming expand-contract animation designed for 4-7-8 and box breathing patterns.
- 🎨 **Earth-Tone Aesthetics**: Soothing natural color palette built with Tailwind CSS.
- ⚡ **Zero Setup**: Pure static HTML/CSS/JS with zero build steps or dependencies. Just open `index.html` in any browser.
